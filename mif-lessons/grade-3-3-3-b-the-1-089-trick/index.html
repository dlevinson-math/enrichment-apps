Launch · 5 min

  1. Write a 3-digit number. Its first and last digits must differ by 2 or more.
  2. Reverse it.
  3. Subtract the smaller number from the larger.
  4. Reverse the difference and add. Always write the difference with 3 digits (write 99 as 099).
